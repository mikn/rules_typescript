### Breaking — ts_dev_server

- Serve `/` and run the dev server from the package containing `ts_dev_server`, rather than the workspace root. Put the target beside the application entry files; `entry_point` may remain in another package. Update old package-prefixed browser URLs to `/`, and add Tailwind `@source` paths for sibling packages. On the optional Vite path, move application environment files, including mode-specific and `.local` variants, from the workspace root beside the dev-server target. For oj, move native `oj.config.*` beside the target; files left at the workspace root are no longer loaded. Rewrite workspace-relative deny patterns for the new dev-server root. Outside that root, use absolute patterns matching real, symlink-resolved paths. Explicitly allow required workspace, real `bazel-bin` and Bazel `node_modules` paths when setting native `server.fs`.
